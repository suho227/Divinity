처음 깃허브에서 프로젝트를 가져왔을 때 해야 할 일
- 1) 리포지토리 클론: `git clone <repo-url>`
- 2) 브랜치 확인/생성: `git checkout -b my-feature` 또는 `git switch <branch>`
- 3) `.env.local` 설정: `.env.local.example`을 복사 후 필요한 환경변수 기입
- 4) Node 버전 확인/설정: `node -v` (권장 LTS 사용), 필요시 `nvm`/`volta`로 설정
- 5) 패키지 설치: `npm install` (또는 `pnpm install`/`yarn install`)
- 6) lint 및 타입체크 실행: `npm run lint` 및 `tsc --noEmit` (선택)
- 7) 개발 서버 실행: `npm run dev` 후 로컬 동작 확인
- 8) Sanity/Supabase 초기화: 필요 시 프로젝트 설정(프로젝트 ID, 키) 확인
- 9) 초기 커밋/푸시 작업: 변경사항 로컬에서 커밋 후 원격으로 PR 생성
- 10) 문서 확인: `README.md`, `TECH_STACK.txt`, `project_environment.txt` 검토
