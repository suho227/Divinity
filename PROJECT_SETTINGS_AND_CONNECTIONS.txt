요약
- 이 문서는 로컬 저장소에 존재하는 환경설정 파일과 외부 서비스 연동 정보를 정리합니다.
- 민감 정보(토큰/비밀키)는 `.env.local`이나 배포 환경에서 관리해야 합니다.

환경파일
- .env.local: 로컬에서 사용하는 환경변수 파일(대개 .gitignore에 포함되어 커밋 금지)
  내용(현재):
    NEXT_PUBLIC_SANITY_PROJECT_ID=o656ekmv
    NEXT_PUBLIC_SANITY_DATASET=production
    NEXT_PUBLIC_SUPABASE_URL=https://your-project-url.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
- .env.local.example: 예시 파일(복사하여 .env.local로 사용)
  항목: NEXT_PUBLIC_SANITY_PROJECT_ID, NEXT_PUBLIC_SANITY_DATASET,
         NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY,
         NEXT_PUBLIC_SANITY_API_VERSION
- .gitignore: `.env*` 항목 존재(환경파일 커밋 방지)

필요/참조되는 환경변수 및 위치
- Sanity
  - 필수 env: `NEXT_PUBLIC_SANITY_PROJECT_ID`, `NEXT_PUBLIC_SANITY_DATASET`, `NEXT_PUBLIC_SANITY_API_VERSION`(선택)
  - 현재 값/설정:
      - `NEXT_PUBLIC_SANITY_PROJECT_ID` = o656ekmv (하드코딩/예비값도 코드에 남아있음)
      - `NEXT_PUBLIC_SANITY_DATASET` = production
  - 관련 파일: src/sanity/client.ts, src/sanity/env.ts, sanity.config.ts

- Supabase
  - 필수 env: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` (public anon 키)
  - 현재 값/설정: 예시 플레이스홀더(실제 값으로 대체 필요)
  - 관련 파일: src/utils/supabase/server.ts, .env.local.example
  - 주의: 서버 전용 키(예: SERVICE_ROLE 키)은 절대 클라이언트에 노출 금지. 배포 환경의 비밀로 관리.

- 기타 외부 연결
  - Google Maps: 프로젝트 문서에 연동 의존성 언급(구체적 키는 코드에 없음)
  - Sanity studio 접속: sanity.config.ts에 `projectId`(o656ekmv), `dataset`(production) 하드코딩 존재
