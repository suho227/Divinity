프로젝트 구조 및 외부 서비스 연동 설명(초보자용)
============================================

1. 이 프로젝트는 무엇을 하는 사이트인가?
---------------------------------------
이 프로젝트는 학교 홈페이지를 만드는 웹사이트입니다. 학교 소개, 학과 정보, 입학 안내, 공지사항, 위치 안내 같은 내용을 사람들에게 보여주는 역할을 합니다.

이 사이트는 단순히 정적인 웹페이지가 아니라, 여러 도구와 연결되어 자동으로 정보를 관리하고 보여주는 형태입니다.

2. 이 사이트는 어떻게 구성되어 있는가?
---------------------------------------
이 사이트는 크게 몇 부분으로 나뉩니다.

- 메인 화면과 메뉴
  - 사용자가 처음 들어왔을 때 보는 화면과 상단 메뉴를 담당합니다.
  - 학교 소개, 입학 안내, 공지사항 등으로 이동할 수 있습니다.

- 언어별 페이지
  - 한국어, 영어, 일본어, 중국어로 페이지를 보여줄 수 있습니다.
  - 사용자가 언어를 바꾸면 자동으로 해당 언어로 화면이 바뀝니다.

- 관리자 페이지
  - 학교 운영자가 내용을 직접 수정할 수 있는 공간이 있습니다.
  - 이 공간은 보통 /studio 경로로 들어갑니다.

- 공통 화면 요소
  - 헤더(상단 메뉴), 푸터(하단 정보)처럼 여러 페이지에서 공통으로 쓰는 부분이 있습니다.

3. 어떤 도구와 연결되어 있는가?
--------------------------------
이 프로젝트는 여러 보조 프로그램과 연결되어 있습니다.

1) Sanity CMS
- 가장 중요한 콘텐츠 관리 도구입니다.
- 학교에서 공지사항이나 입학 안내 문구를 수정할 때 사용합니다.
- 관리자 화면에서 내용을 입력하면, 웹사이트에 자동으로 반영됩니다.
- 즉, 웹페이지를 직접 코딩하지 않아도 내용을 바꿀 수 있는 시스템입니다.

2) Supabase
- 로그인이나 데이터 저장 같은 기능을 위해 연결된 서비스입니다.
- 아직 모든 기능이 바로 연결된 상태는 아니지만, 나중에 사용자 인증이나 데이터 관리에 확장할 수 있는 구조입니다.

3) Google Maps
- 학교 위치를 지도에 표시하기 위해 연결되어 있습니다.
- 위치 안내 페이지에서 지도를 직접 볼 수 있습니다.

4) 외부 웹사이트 링크
- 학교와 관련된 다른 사이트로 연결되는 링크가 들어 있습니다.
- 예를 들어, 학교와 연계된 교회 사이트나 교육 관련 사이트로 이동할 수 있습니다.
- 새 창으로 열리도록 되어 있어서 기존 페이지를 그대로 두고 이동할 수 있습니다.

4. 페이지는 어떻게 내용과 연결되는가?
--------------------------------------
사이트의 각 페이지는 데이터를 받아와서 화면에 보여줍니다.

- 공지사항 페이지
  - Sanity에서 공지사항 목록을 가져와서 화면에 표시합니다.
  - 제목, 날짜, 중요 공지 여부를 보여줍니다.

- 입학 안내 페이지
  - 입학 관련 안내나 양식 목록도 Sanity에서 가져와서 보여줍니다.

- 위치 안내 페이지
  - 지도와 주소, 연락처, 이동 방법을 함께 표시합니다.

5. 한 줄 요약
-------------
이 프로젝트는 “학교 홈페이지를 만들고, 내용을 쉽게 관리하며, 여러 언어와 외부 서비스와 연결해주는 웹사이트”입니다.

즉, 단순한 홈페이지가 아니라, 관리하기 쉬운 스마트한 학교 웹사이트라고 이해하면 됩니다.
